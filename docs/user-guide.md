# IsoBox 使用说明

IsoBox 让微信、QQ、网盘这类你不完全信任的软件，以一个独立的 Windows 账户运行：读不到你的文件，窗口照常显示在你的桌面上，麦克风、摄像头、剪贴板正常可用。它能防住什么、防不住什么，见 [SECURITY.md](../SECURITY.md)。

## 系统要求

- Windows 10 或 Windows 11，64 位
- 你日常使用的账户是**管理员账户**。IsoBox 要装在这个账户里、在这个账户里用：隔离账户的密码、快捷方式和交换文件夹都跟着它
- 要保护的硬盘是 NTFS 格式（内置硬盘基本都是）
- Microsoft Edge WebView2 运行库：Windows 11 自带；Windows 10 多数已经装了，没有的话安装程序会提示下载地址

## 安装

运行 `IsoBox-<版本>-setup.exe`，确认管理员权限后按向导走：

1. **使用前须知**：IsoBox 能防住什么、防不住什么，会对系统做哪些修改
2. **保护设置**：
   - 勾选要保护的硬盘。默认选中所有内置的非系统盘。系统盘不能整盘保护，你的用户目录默认就是隔离的
   - 交换文件夹：你和隔离软件互相传文件的地方，默认是下载文件夹里的 `IsoBox`
3. **安装**：创建隐藏的标准账户 `isobox`，备份并修改选中硬盘的权限。硬盘上文件很多时，备份权限要几分钟
4. 完成后打开 IsoBox

IsoBox 装在 `C:\Program Files\IsoBox`，位置不能改。

### 静默安装

在管理员终端里：

```
IsoBox-0.1.0-setup.exe /S                                   自动保护所有内置非系统盘
IsoBox-0.1.0-setup.exe /S /PROTECT=D:\;E:\                   只保护 D 盘和 E 盘
IsoBox-0.1.0-setup.exe /S /PROTECT=none /EXCHANGE=D:\Swap    不保护硬盘，交换文件夹放在 D:\Swap
```

退出码：0 成功；2 没有安装（例如安装目录里有别的文件）；3 程序装好了，但隔离账户没有建好（打开 IsoBox 点“立即安装”重试）。

## 添加软件

在“软件”页点**添加软件**，选择软件的官方安装包。IsoBox 先分析安装包，然后让你选：

- **安装方式**
  - 快速安装（推荐）：直接把安装包拆开放进库里，不运行它的安装程序。微信、QQ 都可以这样装
  - 运行安装程序：以隔离账户身份运行原版安装程序，安装位置已经填好，一路下一步即可。强制要求管理员权限的安装包装不进去
- **装在哪个库**：库是每个盘上的 `Program Files\IsoBox` 文件夹，见下文
- **显示名**和**开机启动**

装好后桌面和开始菜单的 IsoBox 分组里会出现快捷方式，像平常一样双击启动。

## 日常使用

- **启动**：用桌面或开始菜单的快捷方式，或在 IsoBox 的“软件”页点启动，或用托盘菜单
- **托盘**：在“设置”里打开“开机启动 IsoBox 托盘”。关闭主窗口后托盘继续运行
- **传文件**：隔离软件读不到你的桌面、文档、下载。要发给微信的文件先放进**交换文件夹**；在微信里保存文件时也存到交换文件夹。在“设置”里可以打开或更换它
- **深浅色**：切换系统的深浅色和强调色时，隔离软件会跟着变（托盘运行或启动过隔离软件之后）

## 库

库是每个盘上固定的 `<盘>:\Program Files\IsoBox` 文件夹，隔离软件的程序文件放在这里。系统盘的库在安装时建好。在“库”页可以在其他内置硬盘上建库，在“软件”页把软件移动到另一个库，快捷方式会自动更新。

外接硬盘不能建库：拔掉后库里的软件就打不开了。

## 保护

“保护状态”页列出受保护的位置。可以：

- 保护一个盘或一个文件夹。**系统盘根目录下你自己建的文件夹**（例如 `C:\Work`）默认对所有账户开放，有重要文件的话要在这里单独保护
- 撤销保护
- 用备份还原权限：每次加保护前都会自动备份那个位置原来的权限

U 盘和存储卡多是 FAT32、exFAT 格式，没有权限控制，插着的时候隔离软件也能读到。

## 更新 IsoBox

下载新版本的安装包直接运行即可。你的软件、库、受保护的盘和设置都会保留，正在运行的隔离软件不受影响。

## 卸载

在 Windows 设置的“应用”里卸载 IsoBox，或在 IsoBox 的“设置”页点卸载。卸载程序会：

1. 撤销所有盘上的禁止规则和交换文件夹的授权
2. 删除所有库里的隔离软件
3. 删除隔离账户和它的个人文件夹
4. 删除 IsoBox 本身

**保留聊天记录**：卸载页默认勾选“保留隔离账户的文件”，会先把隔离账户的文档、桌面、下载、图片、视频、音乐文件夹里的文件移到交换文件夹的“隔离账户的文件”里。微信的聊天记录默认在其中的 `文档\xwechat_files`，QQ 的默认在 `文档\Tencent Files`。不勾选的话这些文件会和隔离账户一起删除，无法恢复。

交换文件夹本身的文件始终保留。

## 常见问题

**把文件拖进隔离软件的窗口没反应？**
隔离软件读不到你桌面、下载里的文件。先把文件放进交换文件夹，再从交换文件夹里选。

**在隔离软件里点开的链接，浏览器里没有我的书签和登录？**
隔离软件打开的浏览器也以隔离账户身份运行，用的是隔离账户自己的浏览器设置。可以复制链接到你自己的浏览器里打开。

**复制粘贴能用吗？**
文字和图片可以。复制的“文件”粘贴不过去，原因同上，用交换文件夹。

**提示“隔离账户已经存在，但密码不在当前账户里”？**
IsoBox 是用另一个 Windows 账户安装的。请回到当初安装的账户使用；确实要换账户，先在原账户里卸载，再在新账户里安装。

**出了问题怎么反馈？**
在 GitHub 上提 Issue，附上 Windows 版本、IsoBox 版本，以及在终端里运行下面命令的输出（里面有路径和账户名，发之前看一下）：

```
"C:\Program Files\IsoBox\isobox.exe" status
```

安全问题请按 [SECURITY.md](../SECURITY.md) 私下报告。
