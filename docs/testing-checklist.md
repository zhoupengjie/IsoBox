# 试用清单

给帮忙试用 IsoBox 的朋友。IsoBox 会创建 Windows 账户、修改硬盘权限，虽然卸载时会全部撤销，还是建议先备份重要文件，或者用一台不常用的电脑。

## 先记下你的环境

- Windows 版本：在“设置 → 系统 → 系统信息”里看，例如 Windows 11 专业版 24H2
- 有几个硬盘、各是什么格式；有没有外接硬盘、U 盘、读卡器
- 下载文件夹在不在默认位置（有些人把它移到了 D 盘）
- 日常用的账户是不是管理员；是不是微软账户登录
- 有没有装杀毒软件，装的是哪个

## 按顺序试

1. **安装**：运行安装包。须知页看得懂吗？保护设置页列出的盘对不对？安装用了多久？
2. **打开 IsoBox**：完成页勾着“打开 IsoBox”。打开后在任务管理器的“详细信息”里，给列标题点右键 → 选择列 → 勾上“已提升”，看 isobox-gui.exe 这一行应该是“否”
3. **添加微信或 QQ**：用官方安装包，选快速安装。登录、收发消息、发图片、语音、视频通话
4. **传文件**：把一个文件放进交换文件夹发给别人；把收到的文件存到交换文件夹
5. **确认读不到**：在隔离的微信里“发送文件”，试着打开你的桌面、文档和受保护的盘，应该打不开或是空的
6. **深浅色**：切换系统的深色和浅色模式，隔离软件跟着变吗？
7. **托盘和开机启动**：在设置里打开托盘开机启动，给微信打开开机启动，重启电脑看看
8. **库**：有第二个内置硬盘的话，在那里建库，把微信移过去，再启动
9. **更新**：再运行一次安装包，确认软件和聊天记录都还在
10. **卸载**：在 Windows 设置的“应用”里卸载，保留“隔离账户的文件”。卸载后检查：
    - 交换文件夹里有“隔离账户的文件”，里面有聊天记录
    - 登录界面、“设置 → 账户 → 其他用户”里都没有 isobox 账户
    - 桌面和开始菜单里没有 IsoBox 的快捷方式
    - 你受保护的盘上的文件一切正常

## 怎么反馈

在 GitHub 上提 Issue（选“问题反馈”模板），写上上面记下的环境、在哪一步出的问题、看到了什么（截图最好）。
如果 IsoBox 还装着，附上在终端里运行 `"C:\Program Files\IsoBox\isobox.exe" status` 的输出，发之前看一下里面的路径和账户名。

发现隔离软件读到了不该读的文件这类安全问题，请按 [SECURITY.md](../SECURITY.md) 私下报告，不要公开。
